Cores do vetor

Cada cor é um caminho separado no SVG, de baixo para cima. Desmarque para tirar uma cor, por exemplo o branco numa camiseta branca.

Levar para o VectorCraft

Como abrir no VectorCraft
  1. Arquivo › Abrir e escolha o SVG.
  2. Camadas, de baixo para cima: fundo, imagem e vetor. O vetor tem um caminho por cor (cor-1, cor-2…).
  3. Se o bitmap embutido não aparecer, abra o SVG só vetor e coloque os PNGs por baixo: todos têm o mesmo tamanho e encaixam na posição 0,0.
