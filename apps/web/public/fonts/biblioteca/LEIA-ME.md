# Biblioteca de fontes do VizuVetor

Fontes livres (SIL Open Font License 1.1; Ultra: Apache 2.0) do repositório google/fonts,
usadas para identificar e recriar textos. Todas permitem incorporação no PDF (fsType 0) e
têm os acentos do português. Licenças nos arquivos OFL-*.txt / LICENSE-ultra.txt.
`index.json` lista nome, estilo e licença. Fontes variáveis ficaram de fora (incorporação
no PDF pouco confiável).
