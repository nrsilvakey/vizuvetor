# packages/project-schema

`schema/project.schema.json` — JSON Schema (draft 2020-12) do projeto, versão 1.

Gerado a partir de `services/worker/oae_worker/schema.py` (fonte única):

    python3 scripts/gerar_schema.py

Unidades: milímetros, origem no canto superior esquerdo, Y para baixo.
Tipos TypeScript serão gerados deste schema na etapa 2.
